# Borozdov Keynote

A theme from the Borozdov collection. Two faces — light **Houselights**, tilted frames
floating on a quiet cool-gray canvas, and dark **Blackout**, the same gallery wall after
the lights go down. One vivid blue spark marks every interactive moment; nothing else
in the chrome carries a hue.

![Borozdov Keynote in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/keynote/main/screenshots/light.png)

![Borozdov Keynote in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/keynote/main/screenshots/dark.png)

## Principles

- **The note is the lifted card.** A near-white canvas holds the chrome, a whiter
  (Houselights) or brighter (Blackout) surface holds the note itself — the same
  two-tone relationship a framed print has with the wall behind it.
- **One spark, never a wash.** A single vivid blue marks links, the filled button, the
  caret and the checked box. It never spreads across a whole surface — the rest of the
  interface stays a restrained cool gray.
- **Quiet links.** No underline until you hover; color alone tells you where you can
  go, the way a page of text links reads calmer than a row of buttons.
- **Cards, not boxes.** Callouts, popovers and embeds share one shape: an 18px-radius
  panel with a hairline rim. Tables add the same rim plus the faint lifted shadow of a
  product shot, never a second inner border.
- **System type, full stop.** The platform's own sans at 400 for body text and 600–800
  for headings, with no embedded font — the restraint is the point, and the theme stays
  under 12 KB because of it.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts, code blocks, popovers and embeds drawn as the same hairline-rimmed card
- Tables framed once, by the table itself — no doubled edge where a cell's own border
  used to meet the table's
- A pill-shaped call-to-action button and a pill-shaped filled tag for the one moment
  each needs to read as pressed
- A toggle thumb tuned to stay visible against its own track on both faces
- Text colors meet WCAG contrast on both faces
- The phone layout keeps the same colors and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Keynote**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/keynote/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Keynote/`, then choose Borozdov Keynote under
Settings → Appearance → Themes.
